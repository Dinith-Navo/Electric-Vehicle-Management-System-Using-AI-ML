# Saved Models: Range Prediction
Place Google Colab exported model files here:
- `.joblib` (recommended for Scikit-Learn models like RandomForestRegressor, GradientBoostingRegressor, SVR, XGBoost)
- `.pkl` or `.pickle`

When a file is placed here, the `RangeModelLoader` will automatically detect and load it on next service startup without any code modifications.
